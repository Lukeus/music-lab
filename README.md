# Lukeus Music Lab

A creative portfolio website showcasing experimental music projects, sound experiments, and the creative process behind electronic music production.

## 🎵 About

This site serves as a digital laboratory where musical ideas evolve from concept to completion. It features:

- **Current Projects**: Ongoing musical works with progress tracking
- **Sound Experiments**: Small studies and creative explorations
- **Creative Journal**: Thoughts and insights from the creative process
- **Interactive Elements**: Play buttons, progress animations, and responsive design

## 🚀 Getting Started

### Prerequisites

- Node.js (version 14 or higher)
- A modern web browser

### Installation

1. Clone the repository:
```bash
git clone https://github.com/lukeus/music-lab.git
cd music-lab
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

This will start a live server at `http://localhost:3000` with auto-reload functionality.

### Alternative: Simple Static Server

If you prefer a simple static server without live reload:

```bash
npm start
```

## 🎨 Features

### Interactive Elements
- **Play Buttons**: Toggle between play/pause states
- **Progress Bars**: Animated progress indicators for projects
- **Parallax Effect**: Subtle hero section movement on scroll
- **Responsive Design**: Works on desktop, tablet, and mobile

### Design System
- **Dark Theme**: Optimized for creative work environments
- **CSS Custom Properties**: Easy theme customization
- **Modern Layout**: CSS Grid and Flexbox for responsive layouts
- **Smooth Animations**: CSS transitions and keyframe animations

## 🛠️ Development

### Available Scripts

- `npm run dev` - Start development server with live reload
- `npm start` - Start simple static server
- `npm run lint` - Lint JavaScript files
- `npm run format` - Format code with Prettier

### Code Style

This project uses:
- **ESLint** for JavaScript linting
- **Prettier** for code formatting
- **Modern ES6+** JavaScript features

### Adding Content

#### New Projects
Edit the `.projects-grid` section in `index.html` to add new music projects.

#### New Experiments
Add experiment cards to the `.experiments-grid` section.

#### Journal Entries
Add new entries to the `.journal-entries` section with proper date formatting.
