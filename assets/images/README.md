# Images Directory

This directory contains image assets for the Lukeus Music Lab website.

## Recommended Image Types

### Project Images
- **project-covers/**: Album artwork or project visualization images
- **screenshots/**: Screenshots of music software or creative process
- **waveforms/**: Visual representations of audio waveforms

### General Assets
- **backgrounds/**: Background images for sections
- **icons/**: Custom icon files
- **social/**: Social media preview images

## Image Guidelines

- **Format**: Use WebP for modern browsers, with JPEG/PNG fallbacks
- **Optimization**: Compress images for web delivery
- **Naming**: Use descriptive, lowercase names with hyphens
- **Size**: Optimize for various screen densities (@1x, @2x, @3x)
